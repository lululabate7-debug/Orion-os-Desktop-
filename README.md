# Orion-os-Desktop-
ORION OS Desktop: Linux leggero su Debian 13 con desktop ORION (Wayland, GTK 4), avvio in ASCII art, setup guidato e 7 temi. Per navigare,  gestire VPS e desktop remoti (Termius, Remmina), cloud gaming (Moonlight) e flashare SD e chiavette (Raspberry Pi Imager). Minimo: MacBook Air  4,1 (i5, 2 GB RAM), ma si installa su qualsiasi PC x86-64 UEFI.
